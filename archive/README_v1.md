# Типы муниципальных экономик России: динамическая кластеризация на атрибутированной сети

Решение для онлайн-конкурса СберИндекса 2026, направление «Кластеризация».

Панель **2 016 МО** с полным рядом × 24 месяца (2023-01…2024-12) × 6 категорий расходов, дополненная Росстатом (население, зарплата, занятость по ОКВЭД2),
индексом доступности рынков и дорожными связями СберИндекса. Ещё **173 МО** с неполным рядом получают тип по доступным месяцам с оценённой надёжностью
(один МО, у которого меньше трёх месяцев, назначить нельзя). Заголовочный метод — **GS-TKM** (graph-smoothed temporal k-means): графовое сглаживание признаков,
общие центроиды на все месяцы, траектории типов по Витерби. Два уровня типологии: K=4 (макро) и K=5 (подробный).

## Главное

- **Что получилось.** Четыре макротипа: малые сельские МО (972), индустриальные и средние города (623), столичные агломерации (318), ресурсный Север и Дальний Восток (103).
  96,1% МО за два года не меняли тип; смены пространственно упорядочены: они идут туда, где уже сменили тип дорожные соседи (z = 7,8).
- **Где метод сильнее остальных.** Устойчивость типологии во времени и к инициализации: churn 0,003 в месяц (меньше только у того же метода без графа и у общего k-means с большим штрафом), согласие между запусками (ARI) 0,997 при 0,45–0,78 у DMoN, CANUS, KEFRiN на косинусе и Leiden.
  Проверка вне периода, внутрирегиональная внешняя валидация, три нулевые модели для индексов, воспроизводимость до байта.
- **Где он не лучший, и мы это не скрываем.** По индексам одного среза (ICVI) метод в верхней группе, но не первый: KEFRiN на нормированной сети и спектральный метод выше, а по 5 сидам интервалы мест лидеров пересекаются.
  Сеть **не улучшает** предсказание вне выборки (раздел «Приносит ли сеть что-то сверх атрибутов»). Малые типы (Север и ДВ) на подвыборках держатся хуже крупных. Гипотеза H1 теста вне периода **не подтвердилась**.
  Состав типов заметно зависит от правила, которым строятся рёбра.

## Запуск

```bash
make env            # окружение .venv (Python 3.12) + зависимости; нужен bsdtar для .zip/.rar
make all            # весь конвейер: данные → панель → типы → интерпретация → устойчивость → неопределённость → назначение неполных МО → значимость →
                    # динамика → валидация → тест вне периода → ценность графа → правила ребра → синтетика → настройка базовых методов → сравнение → сравнение по сидам → визуализация
make test           # 25 pytest-проверок: индексы против scikit-learn и igraph, Витерби против полного перебора, DTW против наивной реализации и др.
make verify         # сверка скачанных данных с версионированным SHA256SUMS
make hash           # SHA-256 всех результатов: два чистых прогона должны дать один и тот же вывод
```

Полный прогон на 8-ядерном Mac занимает порядка четырёх–пяти часов; основное время — CANUS (около 70 с на месяц) и сравнение по сидам. Отдельные шаги:
`make headline`, `make interpret`, `make stability`, `make uncertainty`, `make assign`, `make significance`, `make dynamics`, `make validate`, `make outoftime`, `make graphvalue`,
`make edges`, `make synthetic`, `make tune`, `make compare`, `make seeds`, `make viz`. Долгие необязательные: `make selection` (обоснование K, сглаживания и λ), `make leiden-grid`.

### Если загрузка данных падает на сертификате

`www.sberbank.com` и `sberindex.ru` отдают сертификат, выданный национальным корнем РФ
(«Russian Trusted Root CA», Минцифры): после отказа западных центров сертификации выдавать
сертификаты подсанкционным банкам Сбер перешёл на него. Этого корня нет ни в `certifi`, которым
пользуется `requests`, ни в хранилище macOS по умолчанию, поэтому `make data` падает с
`CERTIFICATE_VERIFY_FAILED`, хотя сеть доступна. Росстат отдаётся через Яндекс по GlobalSign и
качается без проблем. Три способа, в порядке предпочтительности:

1. Установить корень Минцифры в хранилище ОС (https://www.gosuslugi.ru/crt) и повторить `make data`.
   Пакет `truststore` из `requirements.txt` берёт доверие из ОС, поэтому корень подхватится сам.
2. Указать свой набор корней: `REQUESTS_CA_BUNDLE=/путь/к/bundle.pem make data`.
3. `make data-sha256` — файлы скачиваются без проверки TLS, но обязаны совпасть с контрольными
   суммами из версионированного `SHA256SUMS`. Доверие переносится с канала на хеш: при расхождении
   файл удаляется и запуск прерывается с кодом 3, а файл, которого нет в манифесте, этот режим
   вообще не примет. Для публичных статических файлов с заранее известными хешами это корректная
   замена проверки канала, но не её отмена.

Все параметры, влияющие на результат, — в [`configs/config.yaml`](configs/config.yaml); сид 42. Подобранные параметры базовых методов — в [`configs/baselines_tuned.yaml`](configs/baselines_tuned.yaml).
Таблицы результатов версионируются в `data/processed/*.csv`, их можно читать без прогона конвейера.

## Что именно сделано и на чём основаны выводы

**Выборка.** В типологию входят только МО с данными за все 24 месяца: 2 016 из 2 190. Раньше пропущенные месяцы дорисовывались константой; у 59 МО было меньше 12 месяцев, у шести — один.
Дорисованный ряд занижает churn и подменяет данные, поэтому такие МО исключены ([`excluded_incomplete.csv`](data/processed/excluded_incomplete.csv)). Это та же выборка, что у публичных решений-конкурентов.

**Сеть.** Для каждого месяца строится граф: косинус по профилю признаков, взаимный kNN (k=15), плюс три ближайших соседа каждому МО. Метод сглаживает признаки один раз по этому графу и ищет общие для всех месяцев центры.

**Устойчивость.** Критерий Хеннига (2007), 20 подвыборок по 80% МО (одни и те же для всех вариантов). K=4: Жаккар по типам 0,963 / 0,928 / 0,945 / **0,806**; три типа высокоустойчивы (>0,85),
«Ресурсный Север и ДВ» только «устойчив» (минимум 0,53, выше порога 0,75 в 60% подвыборок). ARI между разбиениями на подвыборках 0,923 (минимум 0,829), при шуме 0,15σ 0,933, K не схлопывается.
K=5: Жаккар 0,918 / 0,848 / 0,897 / 0,922 / **0,792**; два типа («малые города со смешанной экономикой» и Север и ДВ) «устойчивы», но не высокоустойчивы, ARI подвыборок 0,859 (минимум 0,664), при шуме 0,942
([`hennig_K4.csv`](data/processed/hennig_K4.csv), [`hennig_K5.csv`](data/processed/hennig_K5.csv), [`stability.csv`](data/processed/stability.csv)).

**Неопределённость по каждому МО.** Для каждого МО посчитан запас до границы типа и доля 80%-подвыборок, где оно попадает в тот же тип ([`mo_types_K4.csv`](data/processed/mo_types_K4.csv), [`mo_types_K5.csv`](data/processed/mo_types_K5.csv)).
Пограничными (<75%) оказываются 5,4% МО при K=4 и 8,4% при K=5. Именно они делают малые типы шаткими: при K=5 пограничных 19,5% в типе «Ресурсный Север и ДВ» и 13,1% в «малых городах со смешанной экономикой»
против 5–8% в остальных ([`uncertainty_summary.csv`](data/processed/uncertainty_summary.csv)).

**Покрытие исключённых МО.** 173 из 174 МО получают тип по доступным месяцам (ближайший центр после воспроизведения графового сглаживания по 10 ближайшим полным МО). Надёжность откалибрована на полных МО,
у которых оставлен непрерывный отрезок из m месяцев: совпадение с типом по полному ряду около **94% при K=4 и 86% при K=5** и от числа месяцев (3…18) почти не зависит: ошибку даёт приближение метода,
а не нехватка данных ([`assigned_incomplete_K4.csv`](data/processed/assigned_incomplete_K4.csv), [`assign_calibration_K4.csv`](data/processed/assign_calibration_K4.csv)). В статистику типов эти МО не входят.

**Значимость индексов.** Три нулевые модели по 1 000 реализаций: перестановка меток, перестановка внутри регионов, конфигурационная модель с сохранением степеней. Все индексы значимы против всех трёх нулей
(p = 0,001, пол при 1 000 нулях; наименьшие z: SW 24,9 и 23,1, S_Dbw 3,0 и 4,3 при K=4 и K=5). Средние значения по трём месяцам:

| индекс | SW | CH | S_Dbw | AVI | AVU (вершинный) | MQ | Q | ANUI |
|---|---|---|---|---|---|---|---|---|
| K=4 | 0,178 | 406 | 0,904 | 0,908 | 0,089 | 3,70 | 0,617 | 0,840 |
| K=5 | 0,140 | 362 | 0,819 | 0,852 | 0,136 | 4,41 | 0,651 | 0,764 |

S_Dbw самый слабый из индексов: его значимость зависит от состава выборки (на выборке с дорисованными рядами при K=4 он в одном из месяцев не отличался от случайных меток). AVU меньше — лучше;
MQ у Манкоридиса при сбалансированных кластерах близок к K·AVI, поэтому считается семейством AVI, а не независимым свидетельством ([`significance_K4.csv`](data/processed/significance_K4.csv), [`significance_K5.csv`](data/processed/significance_K5.csv)).

**Дефект референсной метрики AVU.** Индексы AVI/AVU/ANUI/MQ в открытых решениях считаются по формулам
библиотеки Pattern, где AVU и AVI определены на уровне пар кластеров. В этой форме AVU при сбалансированных
внедиагональных блоках тождественно равен (K−1)/(2K−3), то есть определяется одним числом кластеров и не
зависит от качества разбиения; MQ там тождественно равен K·AVI. На стохастической блочной модели с известной
истиной эталонный AVU даёт 0,5712 у истинного разбиения против 0,5714 у случайных меток — отношение 1,000:

| K | AVU эталон: истина / случайно | (K−1)/(2K−3) | AVU вершинный: истина / случайно |
|---|---|---|---|
| 4 | 0,600 / 0,600 | 0,600 | 0,103 / 0,352 |
| 5 | 0,571 / 0,571 | 0,571 | 0,110 / 0,311 |
| 6 | 0,556 / 0,556 | 0,556 | 0,114 / 0,279 |

Мы приводим **оба семейства**: эталонное — для сопоставимости с библиотекой, на которую ориентируется конкурс,
и вершинное (доля веса рёбер вершины, идущая к своим, и к самому притягательному чужому кластеру) — для
содержательных выводов. Расхождение зафиксировано тестом, который упал бы на эталонной реализации
([`icvi_reference.csv`](data/processed/icvi_reference.csv), [`icvi_reference_demo.csv`](data/processed/icvi_reference_demo.csv),
`tests/tests_avu.py`).

**Интерпретируемость.** IMM-дерево (Dasgupta et al., 2020) воспроизводит макротипы порогами с точностью 81,8% при 4 листьях (CART с тем же числом листьев — 82,8%); подробный уровень K=5 — 68,2% при 5 листьях
([`imm_accuracy_K4.csv`](data/processed/imm_accuracy_K4.csv)). Описание формальными понятиями (FCA, в духе Кузнецова) даёт короткие читаемые определения типов: столичные агломерации — высокая доля общепита и низкая продовольствия при высоких тратах
(F1 = 0,87), Север и ДВ — низкая доля здоровья и маркетплейсов при высокой зарплате (F1 = 0,72). Средние типы коротким описанием берутся плохо (F1 0,53–0,59), и это тоже результат:
эти типы лежат на непрерывной шкале. Описание Севера и ДВ находится заново только на 70% подвыборок, остальные крупные типы на 100% ([`fca_K4.csv`](data/processed/fca_K4.csv), [`fca_K5.csv`](data/processed/fca_K5.csv)).

**Динамика.** 96,1% МО при K=4 (94,3% при K=5) не меняли тип ни разу, к концу периода отличаются от начального 71 МО (3,5%). Вероятность остаться в типе за месяц от 0,992 (Север и ДВ) до 0,9998 (агломерации);
время пребывания превышает 22 месяца наблюдения для всех типов, оценка 1/(1−P) цензурируется и не приводится как число ([`transition_month_K4.csv`](data/processed/transition_month_K4.csv)).
Переходы пространственно обусловлены: у МО, устойчиво сменивших тип (≥3 месяцев), доля дорожных соседей, уже находящихся в новом типе, равна 0,464 против 0,257 у сопоставимых не сменивших (z = 7,8; K=5: 0,351 против 0,210, z = 5,6).
Spatial Markov: если тип МО не совпадает с модальным типом дорожных соседей, вероятность смены в месяц в 3,5 раза выше (K=4: 0,0042 против 0,0012; K=5: в 1,8 раза), и 74% таких смен идут именно в тип соседей.
Наблюдения во времени зависимы, поэтому z здесь наивные и приведены как ориентир ([`diffusion_test.csv`](data/processed/diffusion_test.csv), [`spatial_markov.csv`](data/processed/spatial_markov.csv)).

**Внешняя валидация без утечки.** Две линзы: поведенческая (только расходы и их динамика) проверяется на Росстате и доступности рынков, которых нет в её признаках; комбинированная — на доступности рынков и индексе
покупательской мобильности (248 МО), включая срез 2025-11 вне периода построения. Регионы объясняют многое сами, поэтому приведён эффект типа **внутри** региона — прирост скорректированного R² сверх региональных эффектов (K=4, p по
перестановкам внутри регионов): население +0,33, доля занятых в обработке +0,16, в госуправлении +0,07, зарплата +0,04, мобильность 2024-12 +0,03 и 2025-11 +0,01 (p=0,004). По доле занятых в добыче вклад типа внутри региона
незначим (+0,002, p=0,135) ([`validation.csv`](data/processed/validation.csv)). Индекс мобильности почти статичен между срезами (ранговая корреляция 0,97), поэтому проверка вне периода по нему слабая.

**Проверка вне периода (H1 не подтвердилась).** Типология заморожена на 12 месяцах 2023 года (режим только по расходам), цели — прирост 2024 к 2023 по уровню расходов и по доле маркетплейсов,
метрика — OOS MAE на `RepeatedKFold` 5×10. Предзарегистрированная гипотеза H1 «типы не хуже региональных фиктивных переменных» не подтвердилась: типы хуже на 2,1% и 1,7% (K=4; 4 параметра против 73),
на 2,1% и 1,9% (K=5). Добавление типов к региональным эффектам улучшает прогноз на 6,2% и 11,8% (K=4), то есть типы несут информацию, которой нет в регионе
([`outoftime_verdict_K4.csv`](data/processed/outoftime_verdict_K4.csv)). Формулировку мы не меняли.

### Приносит ли сеть что-то сверх атрибутов

Короткий ответ: **не точность прогноза**. Число шагов сглаживания по графу *s* перебрано от 0 (сети в разбиении нет, наш отрицательный контроль) до 3 ([`sgc_select.csv`](data/processed/sgc_select.csv)):

| s | K=4: Жаккар (ср./худший) | AVI | Q | K=5: Жаккар (ср./худший) | AVI | Q |
|---|---|---|---|---|---|---|
| 0 | 0,925 / 0,888 | 0,876 | 0,597 | 0,944 / 0,913 | 0,830 | 0,636 |
| 1 (в конфиге) | 0,910 / 0,806 | 0,907 | 0,617 | 0,876 / 0,792 | 0,850 | 0,651 |
| 2 | 0,917 / 0,830 | 0,910 | 0,620 | 0,759 / 0,590 | 0,854 | 0,654 |
| 3 | 0,909 / 0,828 | 0,910 | 0,620 | 0,761 / 0,603 | 0,857 | 0,650 |

Сглаживание поднимает согласие разбиения с сетью (AVI, Q) и снижает устойчивость: при K=5 средний Жаккар падает с 0,944 (s=0) до 0,876 (s=1), худший кластер с 0,913 до 0,792; при s≥2 K=5 разваливается.
Поэтому в конфиге s=1 как осознанный компромисс: сеть участвует в разбиении, цена видна в таблице. Штраф за смену типа λ на устойчивость почти не влияет и только убирает мерцание
(churn при λ=0 0,014 при K=4 и 0,027 при K=5, при λ=0,5 0,002 и 0,003; [`lam_select.csv`](data/processed/lam_select.csv)).

Почему сеть не помогает, показывает синтетика с известной истиной ([`synthetic.csv`](data/processed/synthetic.csv), среднее по 5 сеансам; 600 узлов, 5 сообществ, 12 месяцев, в шестом 15% узлов меняют сообщество):

| режим | NMI: GS-TKM / без графа | мигранты 0/1/2 мес.: GS-TKM | мигранты 0/1/2 мес.: без графа | ложные смены: GS-TKM / без графа |
|---|---|---|---|---|
| как в реальных данных, граф — SBM по истине | 0,885 / 0,646 | 0,26 / 0,60 / 0,80 | 0,83 / 0,82 / 0,82 | 0,026 / 0,011 |
| граф строится из тех же признаков (как в конвейере) | 0,630 / 0,646 | 0,82 / 0,83 / 0,81 | 0,83 / 0,82 / 0,82 | 0,042 / 0,011 |
| граф из независимого дополняющего сигнала | 0,875 / 0,646 | 0,94 / 0,92 / 0,92 | 0,83 / 0,82 / 0,82 | 0,084 / 0,011 |
| нет устойчивых эффектов узлов | 0,916 / 0,997 | 0,29 / 0,68 / 0,85 | 1,00 / 0,98 / 0,98 | 0,021 / 0,001 |
| шум ×3 | 0,848 / 0,484 | 0,28 / 0,59 / 0,76 | 0,68 / 0,74 / 0,76 | 0,043 / 0,104 |
| дрейф центров | 0,618 / 0,571 | 0,24 / 0,43 / 0,50 | 0,64 / 0,66 / 0,65 | 0,352 / 0,186 |

Если граф построен из тех же признаков, что и разбиение (как у нас), он ничего не добавляет и слегка вредит: NMI 0,630 против 0,646, ложных смен 0,042 против 0,011. Выигрыш 0,885 против 0,646 в первом режиме
получается потому, что граф там — SBM по истинным сообществам, то есть несёт информацию, которой в признаках нет. Это подтверждает режим «дополняющий граф»: сглаживание помогает (0,875 против 0,646), но только если сеть
знает о типах то, чего нет в самих признаках. При отсутствии устойчивых эффектов узлов сглаживание вредит (0,916 против 0,997), при дрейфе центров лучше помесячный k-means (NMI 0,827).
Цена графа во всех режимах: больше ложных смен.

Проверка на реальных данных (`make graphvalue`, [`graph_value.csv`](data/processed/graph_value.csv)): типы 2023 года строятся при разных графах, затем прогноз прироста 2024 вне выборки. Гипотеза H2 (зафиксирована до запуска):
граф из дополняющего сигнала улучшает прогноз. Изменение MAE модели «регионы + типы» относительно s=0 (минус — граф помог), среднее по целям. Поисковые цели — прирост log расходов и доли маркетплейсов,
по которым мы впервые увидели, какой граф помогает; подтверждающие — приросты долей общепита, продовольствия, здоровья и транспорта, на которых графы не отбирались:

| граф для сглаживания | поисковые цели: K=4 / K=5 | подтверждающие цели: K=4 / K=5 |
|---|---|---|
| косинус профиля (те же признаки) | −0,59 % / −0,07 % | −0,05 % / −0,05 % |
| DTW | −0,33 % / +0,27 % | −0,01 % / −0,12 % |
| лаговая корреляция | +0,03 % / −1,03 % | +0,46 % / −0,51 % |
| корреляция приростов | +0,08 % / −0,56 % | +0,56 % / −0,21 % |
| дорожная гравитация | +8,85 % / +9,36 % | +5,22 % / +4,80 % |

Лаговая корреляция выиграла на поисковой цели «log расходов» (−1,9% и −3,1%), но **не воспроизвелась** на подтверждающих (+0,5% и −0,5%): это был эффект отбора среди пяти графов. Дорожный граф стабильно вредит
(+5%): типы превращаются в географию и дублируют региональные эффекты. H2 не подтверждена. Интервалы на изменения (±2 s.e. по повторам) в таблице опущены: повторы кросс-валидации не независимы, и они занижены.
Остаётся то, что сеть даёт согласие разбиения со структурой (AVI, Q), правило ребра как явную гипотезу о том, что считать похожестью, и пространственную интерпретацию диффузии типов.

### Правило ребра: решение, а не деталь

Сравнены девять правил из пяти семейств, ещё 12 вариантов разрежения у трёх ведущих (невзаимный kNN, k=8, k=30, ε-сеть; [`edge_rules.csv`](data/processed/edge_rules.csv), [`edge_rules_jaccard.csv`](data/processed/edge_rules_jaccard.csv)).
Заголовочный метод запускался на каждой сети; колонка «ARI типов» показывает, насколько сам состав типов зависит от выбора:

|---|---|---|---|---|---|---|---|---|
| косинус профиля (в конфиге) | 9566 | 0,178 | 0,908 | 0,617 | 0,276 | 0,910 / 0,806 | 4/4 | 1,00 / 1,00 |
| евклид профиля | 8996 | 0,174 | 0,906 | 0,578 | 0,279 | 0,911 / 0,824 | 4/4 | 0,89 / 0,90 |
| косинус, невзаимный kNN | 21387 | 0,178 | 0,884 | 0,604 | 0,215 | 0,912 / 0,778 | 4/4 | 0,91 / 0,85 |
| корреляция приростов | 8482 | 0,179 | 0,829 | 0,529 | 0,368 | 0,900 / 0,857 | 4/4 | 0,53 / 0,44 |
| форма траектории уровня | 9226 | 0,092 | 0,790 | 0,589 | 0,202 | 0,756 / 0,547 | 3/4 | 0,32 / 0,36 |

| DTW (полоса 3 мес.) | 9258 | 0,172 | 0,911 | 0,604 | 0,280 | 0,918 / 0,883 | 4/4 | 0,73 / 0,54 |
| дорожная гравитация | 20033 | 0,069 | 0,861 | 0,554 | 0,705 | 0,815 / 0,716 | 2/4 | 0,29 / 0,23 |
| слияние трёх | 34395 | 0,156 | 0,778 | 0,497 | 0,489 | 0,923 / 0,866 | 4/4 | 0,64 / 0,40 |

Что из этого следует.
- **Состав типов заметно зависит от правила.** ARI с типами на косинусе: евклид 0,89, DTW 0,73 (K=4) и 0,54 (K=5), лаговая корреляция 0,52 и 0,36, дорожная гравитация 0,29 и 0,23. Макротипы на косинусе и евклиде практически одни и те же; на правилах временных рядов — заметно другие.
- **Явного победителя нет.** Косинус лучший по SW и Q, DTW лучше по AVI и по худшему кластеру (0,883 против 0,806), лаговая корреляция по худшему кластеру ещё лучше (0,882), но слабее по SW и AVI. Косинус оставлен как самый простой и дешёвый,
  а не потому, что он лучше по всем осям. Индексы AVI и Q считаются на той же сети, из которой построено разбиение, поэтому сравнивать правила по ним отчасти круговая задача; устойчивость к подвыборкам от этого свободна.
- Правила из разных семейств почти не пересекаются по рёбрам (Жаккар от 0,025; 28 из 36 пар ниже 0,15): профиль, со-движение, форма траектории, сдвиг во времени и география задают разные отношения между МО.
  Географическое правило воспроизводит патологию «типы = регионы»: 70,5% его рёбер внутри региона против 27,6% у выбранного. Форма траектории уровня разрушает типологию (3 из 4 типов устойчивы).
- Каждая сеть проверена против конфигурационной модели (z по AVI от 66 до 204), то есть ни одна не случайна.
- Лаги: максимум корреляции по лагам смещён вверх (больший лаг укорачивает перекрытие рядов; у 84% пар лучший лаг ненулевой), поэтому лаг ограничен тремя месяцами.

- **Базовые методы запущены воспроизводимо.** Обёртки KEFRiN не пропускают `random_state`, а у CANUS бутстрэп полосы фильтрации идёт на глобальном состоянии torch без генератора: два запуска с одним seed давали разные разбиения.
  Файлы авторов закреплены по SHA-256 и не правятся, сид выставляется снаружи.

## Воспроизводимость

Проверена практикой, а не заявлена. Два независимых прогона с удалением всех таблиц и кэшей (`make hash`, [`scripts/hash_outputs.py`](scripts/hash_outputs.py)): из 53 результатов 51 совпал побайтно, включая CANUS, KEFRiN, синтетику
и правила ребра; `k_sweep.csv`, добавленный в цель make позже, совпал при отдельном запуске, а единственное расхождение, `hennig_static.csv`, объяснено: первый прогон считался до перехода на общий набор подвыборок.
Позднее добавленные шаги (`graphvalue`, `uncertainty`, `assign`, `synthetic` с новыми режимами, `fca_types`, `spatial_markov`) повторены и совпали побайтно; `tune_baselines` и `compare_seeds` (около часа каждый) повторно не прогонялись.

Что было найдено и исправлено при проверке:
- **Неполные ряды** дорисовывались константой (см. «Выборку»).
- **Кэш меток** не зависел от данных и конфига: после смены данных `labels()` вернул бы устаревший файл. Теперь ключ кэша — хеш конфига и панели.
- **Названия типов** держались на порядке по размеру; после исключения неполных МО два типа K=5 поменялись смыслом. Теперь `interpret.py` останавливается, если название не соответствует профилю.
- **igraph** имеет собственный генератор случайных чисел, и `rewire()` не подчиняется засеву numpy: конфигурационная нулевая модель плыла между запусками. Исправлено засевом `ig.set_random_number_generator`.
- **Подвыборки Хеннига** в `hennig_static.py` брались из общего потока по ходу циклов, и разница между вариантами включала шум выборки. Теперь один набор подвыборок на все варианты.
- **Синтетика** с графом-SBM по истинным сообществам помогала графовым методам по построению; добавлены режимы «граф из тех же признаков» и «граф из дополняющего сигнала».

## Что мы считаем слабыми местами

- Подробный уровень K=5 заметно хуже объясняется порогами (68,2% против 81,8% у K=4), два его типа не высокоустойчивы; головные утверждения делаем на K=4.
- Тип «Ресурсный Север и Дальний Восток» шаткий: Жаккар 0,806 (K=4) и 0,792 (K=5), 10–20% его МО пограничные.
- Гипотеза H1 (типы не хуже региональных эффектов вне периода) не подтвердилась; мы оставляем исходную формулировку.
- Сеть не улучшает прогноз вне выборки; её роль в согласии структуры и интерпретации диффузии.
- Состав типов зависит от правила ребра (ARI с DTW 0,73 при K=4, 0,54 при K=5); косинус выбран по простоте, а не по превосходству.
- По индексам одного среза метод не лидер, а S_Dbw нестабилен к составу выборки.
- Индекс мобильности почти статичен между срезами и есть только у 248 МО, проверка вне периода по нему слабая.
- 24 месяца: сезонность оценивается по одному годовому циклу, годовые приросты доступны только за 2024 год. Расходы — модельная оценка СберИндекса, категория «прочее» — остаток.
- Назначение 173 исключённым МО приближённое (около 94% при K=4, 86% при K=5), без настоящего графового сглаживания и динамических дескрипторов.
- Подбор параметров CANUS и KEFRiN сделан на одном месяце по сетке из пяти–десяти конфигураций; более тонкая настройка могла бы улучшить их места.
- Реализация паттерн-кластеризации и пороговой агрегации своя, по опубликованному описанию, а не код авторов.

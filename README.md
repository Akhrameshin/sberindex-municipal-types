# Атлас муниципальных экономик России

**Ахрамешин А. С., Маркелов В. Л.** · Онлайн-конкурс СберИндекса 2026, направление «Кластеризация»

Динамическая кластеризация 1 776 муниципальных образований (МО) по структуре безналичных расходов жителей и экономическому контексту: 5 типов, 13 скользящих годовых окон (декабрь 2023 — декабрь 2024). Метод GS-TKM (graph-smoothed temporal k-means) сглаживает признаки по графу сходства, использует общие для всех окон центры типов и находит траекторию типов по алгоритму Витерби со штрафом за смену типа. Согласие разбиений при 50 пересборках на подвыборках (ARI) — 0,893.

## Запуск

Python 3.12. Подготовленные панель СберИндекса и таблицы Росстата входят в комплект, внешние источники не нужны.

```bash
python3 -m venv .venv && source .venv/bin/activate
python -m pip install -r requirements-core.txt
make core
```

`make core`: выбор числа типов, 50 пересборок для K = 3, 4, 5, шесть правил построения сети, сравнение основных методов, внешняя проверка, калибровка неполных историй, нулевые модели, синтетическая проверка, тесты, отчёт, дашборд, проверка комплекта.

Расширенное сравнение (13 методов, включая KEFRiN, CANUS и DMoN):

```bash
python -m pip install -r requirements-research.txt
make all
```

`make authors` загружает закреплённые исходники KEFRiN и CANUS (нужен интернет; в комплект они не входят). Проверка хешей комплекта: `python scripts/verify_release.py`.

Результаты воспроизводятся на scikit-learn 1.8.0 и 1.9.1, кроме двух расчётов с `GroupKFold` по регионам (кросс-валидация и калибровка присвоения неполным историям): там числа зависят от версии библиотеки.

## Что делает модель

1. Объединяет 247 внутригородских МО Москвы и Петербурга в два города.
2. Берёт МО с 24 полностью наблюдаемыми месяцами расходов; признаки — логарифм уровня расходов и шесть CLR-координат структуры.
3. Добавляет контекст Росстата: население, зарплата, шесть отраслевых долей занятости и нераспределённая занятость.
4. Стандартизует признаки, обрезает на ±4σ, блоки расходов и контекста весят поровну.
5. Строит граф: взаимные 15 ближайших соседей по косинусу профиля расходов, не менее трёх связей на МО.
6. Сглаживает признаки по графу, находит общие центры k-means и траекторию Витерби со штрафом за смену типа.
7. Выбирает самое подробное K из 3–6 с долей наименьшего типа не менее 3% и средним ARI не ниже 0,85; правило сформулировано по ходу анализа и не регистрировалось заранее.

Параметры — в `configs/atlas.yaml`; код — `src/atlas_v2.py`, `src/atlas_experiments.py`, `src/atlas_assignment.py`.

## Результаты

- CSV используют нумерацию типов с нуля; дашборд и отчёт — с единицы. `subsample_agreement` — доля совпадений при пересборке, не вероятность истинного типа.
- Часть смен типа отражает общий сдвиг потребления по стране: после вычитания медианы окна доля сменивших тип за год снижается с 16,9% до 7,8%.
- Из 169 МО с неполной историей 20 получили предварительный тип; согласие с полной моделью в калибровке — 92,2%.
- Тип не улучшает прогноз роста расходов сверх региона и непрерывных признаков; граница типов зависит от весов блоков, сглаживания и длины окна. Типологию следует использовать для исследования и поиска аналогов.

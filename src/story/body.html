02Данные

Признаковое описание муниципального образования

Состояние МО в годовом окне задаётся вектором из 16 признаков двух блоков. Блок расходов (7 признаков) — логарифм среднего месячного уровня безналичных трат на жителя и шесть композиционных координат структуры (здоровье, общепит, продовольствие, маркетплейсы, транспорт, прочее). Доли образуют композицию с единичной суммой, поэтому перед сравнением они преобразуются в центрированные логарифмические отношения (CLR). Блок контекста (9 признаков) содержит логарифм численности населения, логарифм заработной платы, шесть отраслевых долей занятости и долю нераспределённой занятости по данным Росстата за 2023 год.

Признаки стандартизуются по всем окнам вместе, ограничиваются на уровне ±4σ; каждый блок вносит половину суммарной квадратичной нормы вектора. Доступность рынков и объёмы торговли, общепита, жилищного строительства, инвестиций и гостиничных мест в разбиение не входят и используются для внешней проверки. Источники: СберИндекс (расходы, границы МО; CC BY-SA 4.0) и Росстат (CC BY 4.0).

Как пользоваться. Выбранное МО служит сквозным примером для глав 2–4. Его можно сменить кнопками ниже или кликом по карте в главе 1. Полосы сопоставляют структуру расходов МО со средним по его типу и с медианой по выборке.

  • Неопубликованные отрасли. Росстат скрывает часть отраслевых ячеек. Модель использует нижние границы раскрытых долей и явную координату нераспределённой занятости; нулевые значения означают «не раскрыто», а не «отсутствует».

  • Природа данных. Расходы СберИндекса — модельная оценка по безналичным операциям: уровень смешивает объём трат и долю безналичных расчётов, категория «прочее» является остатком. Горизонт в 24 месяца даёт 13 перекрывающихся годовых окон, которые не являются независимыми наблюдениями; контекст Росстата статичен и одинаков во всех окнах.

03Сеть

Сеть сходства: определение и чувствительность результата

Сеть задаётся на множестве МО: вершина — МО, ребро — сходство профилей расходов. Единственного определения сходства не существует, поэтому правило построения рассматривается как гипотеза и проверяется на чувствительность результата.

В основной постановке используется косинусное расстояние между стандартизованными векторами расходов: оно сравнивает форму профиля, а не масштаб. Для каждого МО отбираются 15 ближайших соседей, сохраняются взаимные пары, затем каждому МО независимо от взаимности добавляются три ближайших соседа. Вес ребра равен 1/(d + 10⁻³), нормированному на среднее. В последнем окне граф содержит %%edges%% рёбер; степень вершины — от %%degmin%% до %%degmax%% (медиана %%degmed%%), изолированных вершин нет. Сеть строится только по расходам и не зависит от статического контекста. Только %%within_edges%% рёбер соединяют МО одного региона: сеть связывает похожие экономики через всю страну.

Как пользоваться. Точка — МО (положение приблизительно географическое, цвет — тип). Наведите курсор на точку, чтобы увидеть линии к десяти ближайшим по сходству МО; клик выбирает МО для сквозного примера.

Рис. 3. Ближайшие по сходству МО: точка — МО, цвет — тип

Чувствительность типологии к правилу построения сети

Метод применён к шести сетям: косинус и евклидово расстояние профилей расходов, корреляция приростов, лаговая корреляция (сдвиг до трёх месяцев), DTW годовых профилей с полосой в три месяца и географическая близость центров МО. Для каждого правила приведены доля рёбер внутри региона, пересечение рёбер с основной сетью и согласие получаемых типов с основной типологией (ARI).

Как читать. Чем ниже ARI, тем сильнее типы зависят от определения сходства; ARI = 1 означает совпадение с основным правилом.

  • Состав типов зависит от правила. Евклидово расстояние сохраняет типологию в значительной мере (ARI %%ari_euclid%%), DTW даёт близкое разбиение (%%ari_dtw%%), а корреляция приростов и лаговая корреляция — принципиально иные (%%ari_growth%% и %%ari_lag%%). Тип является ответом на вопрос о том, что считать сходством, а не объективной данностью.
  • Географическое правило воспроизводит административное деление. У географической сети %%within_geo%% рёбер лежат внутри региона против %%within_edges%% у основной сети; ARI к основной типологии — %%ari_geo%%.
  • Правила на временных рядах почти не пересекаются с основной сетью по рёбрам (индекс Жаккара %%jacc_lag%%–%%jacc_growth%%): они описывают иные отношения между территориями.
  • Индексы связности цикличны. Графовые индексы вычисляются на сети, по которой построено разбиение, поэтому высокий индекс на собственной сети не считается доказательством экономической истинности.

Вывод Типология определяется принятой операционализацией сходства. Чувствительность к ней охарактеризована количественно и учитывается при интерпретации.

04Метод

Метод GS-TKM: графово сглаженный временной k-means

GS-TKM (graph-smoothed temporal k-means) скомпонован нашей командой для решения данной задачи. Он объединяет три известные составляющие: сглаживание признаков по графу сходства, единый набор центров для всех окон и выбор траектории типов по алгоритму Витерби со штрафом за смену типа. Цель — типология, имеющая смысл в каждом окне, устойчивая к шуму наблюдений и изменяющаяся только при реальном изменении МО.

  1. Сглаживание по графу. x̃ = Â x, где Â = D⁻¹ᐟ²(A + I)D⁻¹ᐟ²; один шаг (приём упрощённых графовых свёрточных сетей, Wu et al., 2019). Профиль МО усредняется с профилями соседей по сети.
  2. Общие центры типов. Сглаженные векторы всех МО и всех окон объединяются, k-means++ находит K центров один раз (seed 42, 10 запусков). Тип сохраняет смысл во всех окнах.
  3. Траектория со штрафом. Для каждого МО минимизируется сумма квадратов расстояний до центров плюс τ за каждую смену типа, τ = 0,5 × медиана квадрата расстояния до ближайшего центра. Решение при фиксированных центрах точное: динамическое программирование за O(TK) на территорию.

05Динамика

Динамика типов: переходы и общий сдвиг потребления

Анализ переходов выполняется по траекториям, полученным методом GS-TKM. Рассматриваются матрица переходов между первым и последним окном, число смен типа по окнам, вклад общего сдвига потребления по стране и изменение структуры расходов по типам. Динамика описательная: метод не выделяет причины смен.

Как пользоваться. Наведите курсор на ячейку матрицы или столбец гистограммы, чтобы увидеть значение. Кнопка «таблица» под графиком выводит те же данные в виде таблицы. Таблица внизу показывает, как изменилась структура расходов по типам (зелёный — рост, оранжевый — снижение). Число типов меняется переключателем в шапке.

Вывод Большинство МО тип за год не меняют; заметная часть смен отражает общий сдвиг потребления: после вычитания медианы окна доля сменивших тип снижается с %%changed_main%% до %%changed_centered%%. Содержательно общий сдвиг один: доля маркетплейсов растёт во всех типах, доля продовольствия снижается. Следующий вопрос — надёжность самих типов.

06Надёжность

Устойчивость типологии и сопоставление с другими методами

Надёжность оценивается пятью способами: устойчивость каждого типа при пересборке на 80% МО по критерию Хеннига (50 повторов), выбор числа типов, согласие разбиений при трёх значениях случайного seed, сопоставление с 12 методами и вариантами (включая авторские реализации KEFRiN и CANUS из материалов конкурса) по индексам ICVI (SW, CH, S_Dbw, AVI, AVU, MQ, а также ANUI и Q) и проверка индексов против нулевых моделей. Дополнительно метод проверяется на синтетических данных с известной истиной.

На синтетике сеть помогает только при дополнительной информации, а при дрейфе центров метод уступает простым вариантам.

07Проверка

Каждое утверждение работы сопоставлено с результатом проверки. Для каждого указан статус: подтверждено, не подтверждено или подтверждено с оговоркой. Отрицательные результаты в реестре сохранены.

Как пользоваться. Кнопки над списком фильтруют утверждения по статусу; под списком — таблицы с исходными числами.

Вывод Тип не улучшает прогноз роста расходов сверх региона и непрерывных признаков, метод не лидирует по индексам и чувствителен к весам блоков и сглаживанию, а выигрыш от сети не гарантирован. Эти результаты определяют границы применимости: типология — инструмент описания и поиска аналогов, а не прогнозная модель.

  5. Границы применимости. Тип не улучшает прогноз роста расходов; границы типов зависят от весов блоков, сглаживания и длины окна; метод не лидирует по индексам; сеть повышает точность лишь при дополнительной информации; при дрейфе центров метод уступает простым вариантам.

Воспроизводимость

Данные сверяются по контрольным суммам SHA-256, сид зафиксирован, расчёт воспроизводит метки типов, выбор K и пересборки. Набор содержит %%tests%% автоматических проверок; повторный расчёт меток для K = 3, 4, 5 совпадает с таблицами и дашбордом. Две проверки (региональная кросс-валидация и калибровка присвоения неполным историям) зависят от версии scikit-learn: числа в отчёте получены на версиях из requirements-core.txt.

python -m pip install -r requirements-core.txt

make test   # автоматические проверки
